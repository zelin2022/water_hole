# v0 scope

## Purpose

Prove the complete water-selling loop in a small playable prototype, targeting a few hours to a day of development. This is the first of three milestones: first version, Steam demo, full release.

## Included

- One bounded handcrafted test map with sealed edges, stationary earth, several water pockets, and one machine.
- Small square simulation cells (initially 4 pixels), a circular digging brush, and a limited digging reach.
- Water that falls and spreads through excavated space.
- A harmless-water character controller with ground jumping, air steering, automatic airborne wall attachment, unlimited slow climbing, detachment, and wall jumping.
- A 20-unit water tank, suction with E, and hopper-only release with F.
- One credit per delivered water unit; one 60-credit upgrade to a 40-unit tank.
- Full visibility of terrain and water for testing; no hidden-resource system in v0.
- HUD, control hints, restart, browser development, and an Electron desktop window.

## Acceptance

The player can dig into a reservoir, collect water, climb back, sell it, buy the capacity upgrade, then demonstrate carrying more than 20 water. The game identifies that completion and remains playable.

Water must remain accounted for across the world, tank, and delivered ledger, within Float32 rounding tolerance. Repeated empty sales must not create credits. Digging must respect reach and boundaries. Detachment must prevent immediate attachment to the same wall until the player separates.

## Later milestones

Finite procedural generation, artifact placement/searching, the remaining upgrade tracks, additional traversal abilities, hidden-water discovery, saving, sound, organic terrain rendering, and Steam-specific release work are outside v0.

## Validation

Write and run failing deterministic behavior tests before implementation. Run `npm test` and `npm run build` before completion. Use a browser and Electron to check input handling, legibility, movement feel, water flow, and the full loop.
